# 截图（Screenshot）— 使用详情

微信风格的区域截图小工具：在对话框下方点击剪刀按钮（或按全局快捷键 **Alt+A**），拖拽框选或单击两个对角点，截图自动进入系统剪贴板，到任意输入框 `Ctrl+V` 粘贴即可。

## 功能

- **两种框选方式**：按住左键拖拽框选；或单击起点、再单击终点（点选模式自动识别，两次点击距离小于 4px 即进入点选）。
- **跨屏截图**：遮罩覆盖所有显示器的虚拟桌面，可以在副屏上选取，主屏粘贴。
- **可自定义全局快捷键**：默认 `Alt+A`，可改为 `Ctrl+Shift+S`、`F5` 等任意「修饰键 + 主键」组合（支持 Ctrl/Alt/Shift/Win 与字母、数字、F1–F24）。
- **即时进入剪贴板**：截完即贴，不产生临时文件；同时以 PNG 格式写入剪贴板，兼容绝大多数应用。
- **实时尺寸提示**：框选时显示 `宽 × 高`。
- **取消方式**：右键或 `Esc`。

## 使用方法

1. 点击对话框下方的 ✂️ 按钮，或按全局快捷键（默认 Alt+A）。
2. 拖拽框选，或单击起点后再单击终点。
3. 松开（或第二次点击）即完成，图片已在剪贴板，去任意地方粘贴。

## 设置

在按钮上**右键**打开设置面板：

- **快捷键**：点击输入框后按下想要的组合键即可录制。
- **全局热键**：开启后由系统级钩子监听（任何应用获得焦点时都生效）；关闭后仅在 DSH 窗口内响应。
- 保存后立即生效。若所选快捷键被其他程序占用，面板会显示「守护进程异常」警告，换一个组合即可。

## 安装

推荐通过 DSH 插件市场的「发现」页安装（添加本仓库的索引地址后搜索「截图」）。

也可手动安装（在 DSH 会话中对助手说）：

```
用 plugin_manager 安装 git+https://github.com/xypshot/dsh-screenshot.git#<commit>
```

## 运行要求

- Windows 10/11（截图遮罩基于 PowerShell 5.1 + WinForms 实现，系统自带，无需额外依赖）。
- DSH 0.2.0 及以上。
- 多显示器/DPI 缩放环境已做适配（Per-Monitor DPI Aware）。

## 隐私

截图完全在本机原生进程内完成，图片只进入你的剪贴板，**不会上传任何数据**。

## 工作原理

- 客户端按钮通过 DSH 内置 webServer 的同源路由触发宿主端。
- 宿主端拉起一个 PowerShell 遮罩进程（`RegisterHotKey` 常驻守护进程负责全局热键），全屏冻结桌面 → 框选 → 裁剪 → 写入剪贴板。
